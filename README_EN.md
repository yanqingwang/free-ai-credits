## How to read the value columns

- **Recurring value (USD/mo)** — what keeps flowing as long as the deal lives: daily free-tier caps, check-in points, monthly invite rebates, credits-per-day promos. Converted with the vendor's paid price (`est_usd_per_mtok` or `point_value_usd`).
- **One-time value (USD)** — what lands once: signup token/point gifts, trial credits, CN¥ vouchers. Raw amounts, not monthly; the amortization note (if any) sits under the value cell.
- **vs yesterday** — diff against the previous daily snapshot (`data/scan-state.json`): changes in recurring/one-time value, quota figures, type, model lineup, expiry and link health are listed as `old→new`; unchanged rows show "no change", first-time entries show "🆕 new".
- `—` means an uncapped rate-limited tier (value depends on your call density); `⚠️` marks weak sourcing or stale data; 🔒 marks login-walled pages (not dead links).
- **Official sources / Third-party sources columns**: `data/sources.yml` lists what this repo **actually read** during research (official docs/promo pages vs independent media/communities). Both columns filled = cross-verified; one side = single-sourced; rows with neither sink to the bottom. Pages we never opened are never listed — honesty over coverage.
